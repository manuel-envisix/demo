Getzner 3D — Demo-Modus (Admin)

Statisches Hosting: Status liegt in demo-state.json.

  • live — 3D-Erlebniswelt (Standard für Management)
  • start — Ring-Startseite „Eine Aufgabe. Eine Seite.“
  • working — echter Agent-/Pipeline-Status

Lokal / auf dem Server im Repo-Ordner:

python3 uebernehmen.py --demo-live
python3 uebernehmen.py --demo-start
python3 uebernehmen.py --demo-working

Remote ohne SSH: GitHub → Actions → Demo experience mode → Workflow ausführen.
