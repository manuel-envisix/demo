Getzner 3D — Demo-Modus (Admin)

Feature-Flag live-demo in demo-state.json (mit experience).

  • live-demo: false — Ring-Standard „Eine Aufgabe. Eine Seite.“
  • live-demo: true + experience: live — 3D-Erlebniswelt
  • live-demo: true + experience: working — Agent arbeitet

Lokal / im Repo:

python3 uebernehmen.py --live-demo-on
python3 uebernehmen.py --live-demo-off
python3 uebernehmen.py --demo-working

Remote ohne SSH: GitHub → Actions → Demo experience mode → Workflow ausführen.
