# Getzner — 3D Schwingungsschutz-Erlebnis

Interaktive Produktpräsentation: Zug im Alpenkorridor, Schwingungsausbreitung im Boden, Vergleich mit/ohne Getzner-Isolation (Sylodyn®, Sylomer®). Produktbilder von [getzner.com](https://www.getzner.com).

```bash
npm install
npm run dev
```

Build: `npm run build` → `dist/`
